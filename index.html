03 / Principes

Mes principes de livraison.

Une automatisation, ce n'est pas un script qui marche le jour de la livraison — c'est un outil qui doit tenir dans le temps, sans moi. Vous ne serez jamais prisonnier d'un prestataire pour faire tourner votre propre outil.

Documentation incluse

Chaque workflow est livré avec sa documentation technique — pour que ça reste maintenable même si je ne suis plus là.

Monitoring basique

Alertes sur les erreurs critiques, journaux d'exécution, plan de reprise en cas de panne d'API tierce.

Transfert propre

Une session de transfert (visio enregistrée) pour que votre équipe puisse prendre la main. Le code vous appartient, sans dépendance à moi.
